# 三国志 IX 威力加强版武将联携资料库

这是一个关于《三国志 IX 威力加强版》可检索武将资料与兵法联携推荐的项目，由Codex结合GPT-5.6 Terra模型整理得到。

## 主要输出：互动网站

> **[进入《三国志 IX 武将联携》互动网站](https://jiadongm.github.io/san9pk/)**

网站是本项目的主要使用入口。它提供武将浏览、姓名与兵法筛选、武将资料详情，以及按剧本查看三人与五人联携组合及其推荐理由。仓库中的数据、脚本与文档用于支撑和复现这一网站。

## 当前资料

- 650 名武将的姓名、统率、武力、智力、政治、相性与兵法。
- 20 个剧本的开局可用性。
- 已量化的正向联携关系，以及已知应避免同队的负向关系。
- 28 种阵形的名称、用途提示与未解码的原始字段。
- 每个剧本的三人与五人联携优先高分候选。

## 数据状态

只发布由本项目提取、清理和整理的结构化资料，不含游戏可执行文件、剧本二进制或其他原始游戏资源。

相性、兵法和剧本开局可用性来自本地游戏数据的已验证解析。关系亲密度和负向组合来自社区机制资料，详见 [联携模型](docs/linkage-model.md)。阵形的原始数值字段仍未完全解码，因此不会被当作硬性联携评分条件。

## 重新生成数据

将分析资料所在目录传给生成器：

```sh
python3 scripts/build_data.py --source-root /path/to/san9pk-analysis
```

该命令会写入 `data/`，并在写入前检查武将 ID、剧本可用性、推荐组合与负向关系的一致性。

## 网站功能与边界

第一版静态网站已经提供武将浏览、姓名和兵法筛选、武将详情，以及剧本三人／五人组合推荐与评分理由。繁体姓名别名与拼音检索仍在校订；势力筛选将在势力归属字段从剧本数据中解析并验证后加入，避免以不可靠信息做推荐。

GitHub Pages 工作流会在推送 `main` 后更新网站。

后续开发顺序记录在 [网站开发路线图](docs/roadmap.md)。
