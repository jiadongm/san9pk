# 网站开发路线图

本路线图记录《三国志 IX 武将联携》网站接下来的开发顺序。所有功能继续遵守一个原则：明确区分已验证游戏数据、社区整理机制和仍待解析的字段。

## 第一阶段：武将卡与档案

1. 移除人物卡上的相性进度条，改用中性的相性数值和位置说明，避免把相性表现成“越高越强”的能力值。
2. 人物卡补充政治，使卡片统一显示统率、武力、智力和政治。
3. 将已审核的 650 名繁体姓名可靠对应到武将 ID，写入 `nameTraditional` 和 `searchAliases`。
4. 从游戏原始文本提取人物小传，完成逐槽位验证后再接入武将数据；在此之前，展开档案不显示外部整理小传。
5. 以曹操、刘备、孙权、张角等代表人物作为相性圈锚点，设计相性参考区域。区域不得冒充剧本中的实际势力归属；颜色优先从原游戏界面或资源中核对。

## 第二阶段：组合筛选

1. 已完成：从游戏原始剧本的 `forc`、`city` 与 `bldg` 记录解析每个剧本的开局势力，并提供“剧本＋势力”筛选。无可验证归属的武将不归入任何势力成员池。
2. 增加四维限制：队伍最高统率、武力、智力或政治不得低于用户设定值，并评估是否需要队伍平均值门槛。
3. 筛选后只显示满足条件的候选。如果预生成组合不足，再评估浏览器端即时组合计算，不以隐藏少量既有结果冒充完整搜索。
4. 每个结果继续说明相性、正向关系、负向关系排除、兵法覆盖和四维门槛。

## 第三阶段：相性圆环

1. 用完整的 0–149 圆环表达相性是循环距离，而不是能力高低。
2. 支持鼠标、触控和键盘选择圆环位置，并显示附近武将。
3. 标记参考区域和代表人物；点击武将可直接打开详细档案。
4. 为手机提供不裁切、不依赖精确拖动的紧凑交互。

## 第四阶段：资料探索

1. 四维单项、四维总和及其他明确指标的排序。
2. 按四维范围查找武将。
3. 四维分布和异常值浏览。
4. 武将四维聚类，以及相性区域与能力分布的交叉观察。

聚类与统计结果必须标为探索性分析，不得表述成游戏官方分类或隐藏公式。

## 当前执行顺序

下一批实现优先增加队伍四维门槛：允许按队内最高统率、武力、智力和政治筛选当前剧本或势力的候选。游戏人物小传须在原始文本提取并验证后再加入；相性圆环与资料探索排在核心筛选体验之后。
