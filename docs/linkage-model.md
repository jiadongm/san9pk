# 联携模型与限制

## 当前推荐规则

1. 只从对应剧本开局可用的、具有完整基础资料的武将中选人。
2. 任何包含已知负向关系的一队都会被排除。
3. 每一对武将的基础联携分为 `25 + 5 × max(0, 5 - 环状相性距离)`，再加上已量化的正向亲密度。
4. 队伍分数是所有两两配对分之和。统率、武力与智力平均值仅在同分时排序，不进入联携分。
5. 兵法和阵形提示用于解释部署方向，不会在阵形机制尚未完全验证时强行加权。

网页中的统、武、智、政门槛是展示筛选：每项会检查该队伍是否至少有一名武将达到用户填写的数值，不会改变联携分或原始排序规则。

## 证据与限制

- 游戏内人物记录解析支持相性、兵法与剧本开局可用性字段。
- 正向亲密度与负向组合来自社区机制资料，属于整理后的可审计输入，不应视作官方公开公式。
- 五人组合采用宽度 300 的束搜索，结果是高分候选，而非所有可能组合的穷尽最优证明。
- 钟会与邓艾等已知负向组合会被排除。
